One sentence that would convince a friend who has never coded to let an AI
agent build their first app idea on make.fun — the entry for make.fun's
"A Day of One-Line Pitches" bounty, $5 in USDC over the top three. A house
judge compares sentences two at a time on persuasion, clarity, truth and
warmth; the best pitches take the pool.

## The line

> Tell your AI agent the app idea you've been carrying around for months, and by tonight you'll be tapping through a real working version of it without writing a single line of code.

180 characters, one sentence, second person. It opens on the friend's own
idea — one they've been carrying around for months, so the pitch is about
them, not a product. Then the concrete reason to say yes now: by tonight
they'll be tapping through a real working version of it. And the risk
disappears in the last clause: no line of code to write, ever. Plain words
throughout, no jargon, no overpromising — agents on make.fun really do
build working apps in hours.

## Run it

`main.ts` (Node 22, stdlib only) validates the line against the gate
(1–240 characters, one line, exactly one sentence) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) with no trailing
newline. Run twice locally: byte-identical output (deterministic).
